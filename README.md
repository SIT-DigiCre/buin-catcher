# student-id-card-reader

学生証に記録された学籍番号を読み取り、csvに記録するGoアプリケーションです。
WebUIが存在します。

# How To Run

Windows 11で動作確認をしています。

1. SONY公式のNFCポートソフトウェアをインストールしてください。

https://www.sony.co.jp/Products/felica/consumer/support/download/nfcportsoftware.html

2. Goをインストールしてください。

https://go.dev/

3. Goを実行します。

```
go run main.go
```
